# PoliTO Course Materials — AI & Data Analytics

Course materials, notes, labs, exercises and slides from the **Artificial Intelligence and Data Analytics**
program at Politecnico di Torino (a.y. 2024/25 – 2025/26). Two academic years, all courses I attended.

## Structure

```plaintext
/
├── first-year/
│   ├── first-semester/
│   │   ├── architetture-dei-sistemi-di-elaborazione/   # labs, notes, slides
│   │   ├── big-data-processing-and-analytics/          # exercises, labs, notes, slides
│   │   ├── computer-network-technologies-and-services/ # notes, slides
│   │   └── data-science-and-database-technology/       # homework, notes, slides
│   └── second-semester/
│       ├── machine-learning-and-pattern-recognition/   # exam, labs, notes, projects, slides
│       ├── programmazione-di-sistema/                  # exam, labs, notes, project, simulations, slides
│       ├── software-engineering/                       # exercises, geocontrol-project, labs, notes, simulations, slides
│       └── web-applications-1/                         # labs, notes, slides
└── second-year/
    ├── first-semester/
    │   ├── advanced-machine-learning/                  # labs, notes, paper, project, slides
    │   ├── deep-natural-language-processing/           # exam-simulations, labs, notes, project, slides
    │   ├── large-language-models/                      # exam, labs, notes, project, slides
    │   └── robot-learning/                             # journals, labs, notes, project, slides
    └── second-semester/
        └── explainable-and-trustworthy-ai/             # labs, notes, slides
```

Each course folder follows the same convention: `notes/NN-topic/NN-topic.md` for notes,
`labs/lab-NN/` for lab work, `slides/` for the professor's slide decks, plus course-specific
folders (exam material, projects, simulations).

## Notes format

Markdown with Obsidian-style frontmatter, written in English, one folder per topic
(`NN-slug/slug.md`). Some second-year courses also ship pre-rendered PDFs of the notes.

## Datasets not included

A few Deep NLP lab notebooks reference datasets (language identification, news headline
classification, wiki plots, Italian–English parallel corpus) that are **not** stored in this
repository (~115 MB). Obtain them from the course lab pages before running those notebooks.
